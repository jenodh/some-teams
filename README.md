# Some Teams

Some Teams is a website showcasing women's football teams from different countries and leagues. Each team is presented in a card with information about the team, its city, league and UEFA coefficient ranking, along with a link to its official website.

The project was created as part of my web development studies at Yrgo in Gothenburg, Sweden.

## Features

- Displays women's football teams using data stored in a PHP array.
- Shows team information, including city, league and UEFA coefficient ranking.
- Includes a homepage and an About page.
- Uses reusable PHP components for the header and footer.
- Responsive layout for desktop, tablet and mobile screens.

## Technologies

- HTML
- CSS
- PHP
- Git and GitHub

## Getting Started

### Prerequisites

To run this project locally, you need PHP installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/jenodh/some-teams.git

   ```

2. Navigate to the project directory:
   cd some-teams

3. Start the PHP development server:
   php -S localhost:8000

4. Open the following URL in your browser:
   http://localhost:8000
